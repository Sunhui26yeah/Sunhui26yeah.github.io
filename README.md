# Hui Sun — Personal Academic Website

Source for [sunhui26yeah.github.io](https://sunhui26yeah.github.io), built with [Jekyll](https://jekyllrb.com/) using the [Academic Pages](https://github.com/academicpages/academicpages.github.io) template.

## Local development

```bash
bundle install
bundle exec jekyll serve
```

Then visit `http://localhost:4000`.

## Structure

- `_pages/about.md` — homepage / bio
- `_pages/cv.md` — CV page (education, experience, skills, publications)
- `_publications/` — one file per publication
- `_config.yml` — site-wide settings and sidebar profile info
- `files/` — downloadable PDFs (CV)
- `images/` — profile photo and other images
